# debayer — BAYER-RESIDUAL CONTRACT v1 prototype

Tiny residual debayer: RGGB mosaic -> RGB as
`clamp01( passthrough( MalvarHeCutler(m) + f_theta(m) ) )`,
where `f_theta` is a 5,616-param bias-free 4-layer 3x3 CNN (leaky-ReLU 1/16,
9x9 receptive field, no norm/attention/bias) trained with MLX. See `report.md`
for the full PSNR table, BR1–BR5 law results, and the Metal kernel spec.

## Reproduce

```
/opt/homebrew/bin/python3 train.py            # ~52 s end-to-end on Apple GPU
/opt/homebrew/bin/python3 train.py --epochs 2 # smoke test
```

Deterministic (seed 20260716). Requires: mlx 0.30.1, numpy, Pillow, and the
four Photo Booth JPEGs in `~/Pictures/Photo Booth Library/Pictures/`
(last one in sorted order is the held-out photo).

## Artifacts (regenerated by train.py)

- `weights.npz` / `weights_fp16.npz` — conv weights `c1..c4`, MLX layout (O, kH, kW, I).
- `golden.npz` — 4 fixed 32x32 mosaics (flat, checker2, natural, gradient_noise)
  with exact FP32 operator outputs: the Metal parity targets.
- `results.json`, `train_log.txt`, `report.md`.

## Result summary

BR5 gate PASS: student +3.72 dB over bilinear (mean per-patch CPSNR, held-out).
All laws BR1–BR4 pass numerically; BR2/BR3 exact by construction, BR4 exact up
to FP roundoff (bias-free net is positively homogeneous).
